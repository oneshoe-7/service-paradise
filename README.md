# Service Paradise

A multi-page service booking web app built with React and Vite — connects customers with service jobs (like cleaning, construction, repair, and installation) in a clean, easy-to-use interface.

## Features

- 🛠️ Browse available service jobs (cleaning, construction, repair, installation)
- 🛒 Cart system for selecting/booking services (via Context API)
- 💬 Customer service page
- 📱 Multi-page navigation with React Router
- 🎨 Soft violet-to-pink gradient UI with card-based layouts

## Tech Stack

- **React** – UI library
- **Vite** – build tool & dev server
- **React Router** – client-side routing
- **Context API** – global state management (cart)
- **CSS** – custom flexbox layouts, gradients, card designs
